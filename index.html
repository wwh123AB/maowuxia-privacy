猫武侠隐私政策

运营主体　王无敌的工作室

更新日期　2026年11月13日　·　生效日期　2026年11月13日

王无敌的工作室（以下简称“我们”）提供《猫武侠》游戏服务。本政策说明游戏数据的处理方式、您联系我们时涉及的信息，以及您管理个人信息的途径。请在使用游戏服务前阅读本政策。

本政策适用于《猫武侠》的本地存档功能，以及集成 TapADN 5.3.3.0 的安卓广告版本。广告相关条款适用于包含该功能的安装包。游戏后续增加账号或其他联网功能时，我们将按实际功能更新本政策，并履行相应告知与授权程序。

一、本地游戏数据

为保存和恢复游戏进度，游戏在您设备的应用存储空间内保存战役存档、角色成长、物品与队伍状态、游戏内事件记录、奖励领取记录，以及画面、声音和操作设置。九个存档槽位分别保存所选进度，备份文件用于恢复有效存档。

上述数据用于在当前设备继续游戏、应用您的设置和执行游戏规则，保存期限随您使用游戏及管理设备数据的情况而变化。您可以通过设备系统的应用存储管理功能清除本地数据。清除后，相应存档、备份和设置将受到影响，请先核对要删除的内容。

二、客服与问题反馈

您通过邮箱联系我们时，我们会处理您主动提供的邮箱地址、来信内容及附件，用于答复咨询、核实问题、处理投诉或响应个人信息权利请求。为定位故障，我们可能请您补充游戏版本、设备型号、系统版本及问题发生过程。

反馈截图、日志或存档前，请检查其中的内容，并仅提供解决当前问题所需的信息。客服通信通过电子邮件服务处理，邮箱服务商按其适用的服务条款和隐私政策处理邮件传输与存储。

三、设备权限与第三方服务

游戏通过应用自身存储空间保存进度。安卓广告版本使用联网和网络状态权限加载广告；广告内下载应用时，SDK 可能使用安装应用权限，安装操作由您在系统提示中决定。

安卓广告版本集成 TapADN SDK 5.3.3.0，提供方为上海艾得蒽数字科技有限公司。SDK 在您同意后初始化，在您主动使用激励广告时用于广告展示、奖励校验、效果统计、归因、反作弊及稳定性诊断。

SDK 自行处理的信息包括 IP 地址与网络连接状态、设备品牌和型号、操作系统、语言、时区、屏幕参数、CPU 与可用空间信息，应用包名、版本、运行进程与前后台状态，以及广告展示、点击、转化、崩溃和性能记录。数据处理和保存详情见 TapADN SDK 隐私政策。

本游戏通过 SDK 控制器关闭位置、电话状态及设备序列号、Wi-Fi 详情（含 SSID、BSSID）、MAC 地址、传感器、外部存储、应用列表、Android ID 和 OAID 的访问开关，关闭摇一摇交互。SDK 的具体处理能力同时受系统权限与设备条件约束。

您可在标题界面的“隐私与广告”中阅读政策、开启或关闭个性化广告、撤回广告服务同意。个性化广告默认关闭。拒绝同意后可继续使用本地游戏功能；需要观看广告的奖励须完成广告服务授权。撤回后游戏停止发起广告请求，下次启动按撤回状态处理 SDK 初始化。

您使用应用商店、系统备份或设备平台提供的服务时，相应服务提供方按其自身隐私政策处理相关信息。

四、信息存储与安全

本地存档和设置保存在您的设备应用存储空间中。客服信息保存在用于处理来信的邮箱及必要的工作记录中，保留时间以处理咨询、故障、投诉和履行适用法律义务所需的期限为限。处理目的完成且相应保留义务结束后，我们将删除或匿名化相关记录。

我们根据所处理信息的性质采取访问权限控制、必要范围内的使用和相应的数据保护措施。请妥善管理您的设备、存档副本和电子邮件，避免向无关人员提供包含个人信息的材料。

五、共享、转让与公开披露

涉及向第三方共享、转让或公开披露您的个人信息时，我们将根据具体情形说明接收方、处理目的、方式和信息种类，并履行适用的告知、同意或其他法定程序。依法响应有权机关要求时，将按其权限和适用法律规定处理。

因运营主体变更等原因需要转移个人信息的，我们将告知接收方名称与联系方式，并要求接收方继续依法履行个人信息保护义务。

六、您如何管理个人信息

您可以通过设备系统管理本地游戏数据，或通过本政策列明的邮箱申请查阅、复制、更正、补充、删除我们处理的个人信息，以及撤回相关授权、提出投诉或寻求解释。

我们收到请求后，会根据请求内容核实必要信息，在适用法律规定的期限内处理并反馈。涉及依法必须保存的信息，将按照相应保存义务处理，并向您说明处理结果。撤回同意后，相关功能的可用性以实现该功能所需的信息处理条件为准。

七、未成年人信息保护

未成年人应在监护人指导下阅读本政策，并在监护人同意和指导下使用游戏。涉及不满十四周岁未成年人个人信息的处理，我们将依照适用法律落实监护人同意和相应保护要求。

监护人对未成年人信息处理有疑问，或需要查阅、更正、删除相关信息时，可以通过本政策列明的邮箱联系我们。

八、政策更新

当游戏功能、所接入的第三方服务或信息处理方式发生变化时，我们将及时更新本政策。重要变更会通过游戏内提示或其他适当方式通知您，并在需要时重新取得同意。页面顶部会列明更新日期和生效日期。
